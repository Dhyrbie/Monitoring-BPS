# Monitoring-BPS
Sistem Monitorng untuk mengetahui kinerja para petugas Badan Pusat Statistik menggunakan Apps Script yang dapat menunjukkan informasi berdaasarkan data kinerja petugas, menu form progress untuk user(petugas) dapat mencatat berapa target yang suudah mereka dapatkan, dan menu tambah tugas untuk admin menginput penugasan baru.
